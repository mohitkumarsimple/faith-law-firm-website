# Faith Law Firm website

Multi-page website for Faith Law Firm, a Delhi-based legal chamber.

## Included routes

- Home, About, Practice Areas, Founder & Team
- Legal Insights with six article pages
- Publications with four printable research-note pages
- Advocate Careers and Internship Programme
- Contact and Privacy Policy

## Local commands

```bash
pnpm install
pnpm run dev
pnpm run build
```

The consultation and application forms currently prepare an email in the
visitor's email application. A server-side form provider can be connected once
the firm supplies the approved endpoint and data-retention settings.
